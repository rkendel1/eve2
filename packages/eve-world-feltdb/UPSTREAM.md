## What changed, and why

| Upstream                                                                                                                                  | Here                                                                                                                                                                                                                             | Why                                                                                                                                                                          |
| ----------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| SQLite database (`db/index.ts`, `db/driver.ts`, `db/schema.ts`): synchronous `transact` with reads inside a `BEGIN IMMEDIATE` transaction | `world/database.ts`: one FeltDB transaction per unit of work. Units are serialized in the process; reads see the unit's own staged writes; every record read or written is guarded with `ifVersion` or `requireAbsent` at commit | FeltDB has no reads inside a transaction. Guarding every read record makes a unit's decisions hold at commit or the commit fails, which is what the write lock gave upstream |
| SQL tables and indexes                                                                                                                    | FeltDB collections `wf_*` with compound indexes declared at open                                                                                                                                                                 | No SQL on this path                                                                                                                                                          |
| `Store` (synchronous)                                                                                                                     | `world/store.ts` (reads async, writes staged synchronously)                                                                                                                                                                      | FeltDB reads are async; staging writes synchronously keeps every upstream write call correct without an `await`                                                              |
| `MAX(seq)` over events                                                                                                                    | the run record's `seq` counter, updated with every append in the same commit                                                                                                                                                     | A position is decided by a guarded run record, so two writers can never take one position                                                                                    |
| Documents stored inline                                                                                                                   | Documents above `inlineDocBytes` (default 1 KiB) are written through a `PayloadStore` before the commit and referenced, with the payload's guard in the commit                                                                   | Bounded FeltDB memory; a committed reference never names missing bytes                                                                                                       |
| Record ids are SQL keys                                                                                                                   | FeltDB keys `[A-Za-z0-9._-]`: plain ids kept, others replaced by `x<sha256>`, original values stored in the record                                                                                                               | FeltDB's key alphabet                                                                                                                                                        |
